The Polaris Express API is split into ten namespaces. Customer and
admin endpoints live behind authenticated sessions (<Glossary term="BetterAuth">BetterAuth</Glossary>); the
<Glossary term="OCPP">OCPP</Glossary> namespace receives HMAC-signed webhooks from <Glossary term="SteVe">SteVe</Glossary>; the webhook
namespace receives signed callbacks from <Glossary term="Lago">Lago</Glossary>.
