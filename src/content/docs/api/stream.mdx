The `/api/stream/*` namespace exposes [<Glossary term="SSE">SSE</Glossary>](/glossary#sse) endpoints
for real-time updates (session state, [<Glossary term="ChargeBox">ChargeBox</Glossary>](/glossary#chargebox)
status, [meter value](/glossary#meter-value) ticks). Each stream is a
long-lived `text/event-stream` response — clients reconnect on close
and resume via `Last-Event-ID` where supported.

## Base URL

Customer streams are served from the customer host; admin streams
from the admin host. Both paths share the `/api/stream/` prefix.

## Authentication

All stream endpoints require an authenticated session cookie
([<Glossary term="BetterAuth">BetterAuth</Glossary>](/glossary#betterauth)). Anonymous connections are
rejected with `401` before the stream opens. EventSource in the
browser sends cookies automatically when the stream is same-origin;
cross-origin consumers must use a fetch-based SSE client with
`credentials: "include"`.
