<Persona for="Selfhoster">
  Polaris Express is built to be self-hosted. This guide walks you
  from a blank machine to a running stack: SteVe (OCPP backend),
  Postgres, the Fresh web app, the sync worker, and the Cloudflare
  email Worker.
</Persona>

The install splits into eleven ordered phases. Each phase has a
dedicated runbook with prerequisites, exact commands, and verification
checks. Don't skip ahead — later phases assume earlier ones completed
cleanly.
