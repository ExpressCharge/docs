The `/api/ocpp/*` namespace receives webhook callbacks from [SteVe](/glossary#steve) when [OCPP](/glossary#ocpp) events occur on a [ChargeBox](/glossary#chargebox) — session lifecycle, [meter values](/glossary#meter-value), status notifications, and authorization checks. Polaris Express consumes these events to drive session state, billing, and live UI updates.

These endpoints are server-to-server. They are not part of the customer or admin API surface.

## Base URL

```
https://admin.polaris.express
```
